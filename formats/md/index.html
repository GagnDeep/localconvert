Frequently asked questions

What is a .md file?

Markdown uses simple symbols like # and * to describe headings and emphasis. LocalConvert renders Markdown into polished PDF, HTML or rich text.

How do I open a Markdown file on iPhone?

Tap it in Files to preview with Quick Look. LocalConvert converts it to PDF.

What's the best format to convert Markdown to?

For most people, PDF. Documents that look identical on every device. LocalConvert can also convert Markdown to TXT, RTF and HTML.

Is Markdown compressed?

No. Markdown stores data uncompressed, which keeps it simple but makes files larger.

Is it safe to open Markdown files with LocalConvert?

Yes. LocalConvert processes files on your device and never uploads them, so your documents stay private.
