What is a IIQ file?

IIQ is Phase One's camera RAW format. It keeps the untouched sensor data so you can recover highlights, shadows and white balance. It is used by Phase One medium-format backs. LocalConvert develops the RAW file on-device and exports a ready-to-share JPG, HEIC, PNG or TIFF.
