What is TSV?

TSV avoids the quoting headaches of CSV by using tab characters between columns. It is popular in bioinformatics and when pasting from spreadsheets.

What is CSV?

CSV stores a table as plain text, one row per line. Every spreadsheet, database and analytics tool can import it. LocalConvert converts CSV to JSON, TSV, HTML tables and PDF.
