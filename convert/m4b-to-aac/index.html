What is M4B?

M4B is an AAC audiobook format that supports chapters and remembers your position. Unprotected M4B files can be converted to M4A, WAV or other formats.

What is AAC?

A .aac file is a bare AAC stream without the MPEG-4 wrapper. It is used by some radios, streaming tools and Android apps.
